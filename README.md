# stupidCensor

Legacy script-аддон PulseSync для Яндекс Музыки: поиск альтернативных записей и облачная подмена цензурированных треков через публичный GitHub-репозиторий пользователя.

Автор:  **Xaunds** · версия **1.5.0**.

## Возможности

- Пункты меню трека: **«Найти без цензуры»** и **«stupidCensor: открыть»**.
- Автопоиск и автосохранение уверенных совпадений; при сомнении — подтверждение в панели.
- Пометка **SC** у треков с активной заменой.
- Поиск через GitHub Actions (`workflow_dispatch`) и yt-dlp: YouTube и SoundCloud.
- Поиск только по метаданным: аудио не скачивается и не публикуется до подтверждения.
- Публикация выбранного файла в GitHub Releases и запись в `list.json`.
- Автоматическая регистрация подмен по ID трека.
- Отмена заданий, ориентировочное время и статусы без ручного обновления.
- Ручное добавление по прямой HTTPS-ссылке или странице YouTube/SoundCloud.
- Массовый поиск для текущей очереди Яндекс Музыки.
- Общая библиотека для друзей: достаточно публичного репозитория, токен не нужен.
- Права владельца: журнал Actions, удаление из `list.json`/Releases и проверка заявок доступны только владельцу.
- Добавления друзей проходят через GitHub Issues. Кнопка «Принять» запускает локальную загрузку на компьютере владельца.
- Локальный помощник скачивает выбранную запись, загружает готовый M4A в Releases и удаляет временные файлы. Друзья получают уже готовую замену из общей библиотеки.
- YouTube: локальные cookies из браузера для помощника; для GitHub Actions доступны `YTDLP_COOKIES` и `YTDLP_PROXY`.
- Библиотека, настройки GitHub и режим чтения без токена.

## Локальная загрузка

Скачайте `stupidcensor-local-helper` из Releases, установите ffmpeg (`brew install ffmpeg`), сохраните token владельца через `install-token.command` и запустите `start-local-publisher.command`. Terminal должен оставаться открытым. Cookies читаются из Chrome локально; для Firefox задайте `STUPIDCENSOR_BROWSER=firefox`.

После кнопки «Принять» в панели помощник скачивает запись, публикует её в Releases и закрывает заявку. `uncensor-approved` остаётся запасным вариантом для GitHub Actions.

Подробности — в `addon/README.md`, `tools/README-local.md` и `setup-ru.html`.
