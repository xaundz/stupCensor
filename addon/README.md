# stupidCensor

Облачная библиотека замен для цензурированных треков Яндекс Музыки.

Аддон ищет альтернативные записи через GitHub Actions, показывает кандидатов и скачивает только выбранный файл в Releases вашего публичного репозитория. После публикации запись попадает в `list.json` и автоматически регистрируется как подмена для трека по его ID.

## Что важно

- Нужен **публичный** GitHub-репозиторий: аудио должно открываться без авторизации.
- Нужен fine-grained token с правами **Contents: Read and write**, **Actions: Read and write**, **Metadata: Read**. Для классического token — `repo` и `workflow`. Другу для заявок достаточно **Actions: Read and write**, **Contents: Read**, **Metadata: Read**.
- Автосохранение выполняется только при уверенном совпадении; при сомнении аддон открывает панель для подтверждения.
- Поиск читает только метаданные. Аудио скачивается после подтверждения, поэтому в Releases не появляются временные превью.
- Задание можно отменить во вкладке «Задания»; там же показывается примерное время.
- Массовый поиск запускает задания для треков текущей очереди.
- Общая библиотека друзьям доступна без токена: они видят замены владельца и скрывают их только у себя.
- Для добавления другу нужен личный токен; его выбор создаёт Issue и публикуется только после подтверждения владельцем.
- Журнал Actions, удаление из GitHub и проверка заявок доступны только владельцу репозитория.
- Поиск: YouTube, SoundCloud, Rutube и Dailymotion. В ручную ссылку можно вставить страницу YouTube, SoundCloud, Rutube, Dailymotion, Vimeo, Bandcamp или VK.
- YouTube часто требует вход с IP GitHub Actions. Добавьте cookies в секрет `YTDLP_COOKIES` (или прокси в `YTDLP_PROXY`) и проверьте доступ кнопкой в настройках. SoundCloud с DRM помечается как недоступный; worker пробует резервный источник.
- Аудио перекодируется в M4A/AAC 160 kbps для совместимости с плеером.
- Токен хранится в локальном хранилище аддона, если включена галочка «Хранить токен». Не публикуйте его.

## Установка

1. Разместите файлы из папки `repository-template` (в архиве выпуска) в корне публичного репозитория.
2. Создайте токен и подключите репозиторий в разделе **«GitHub»**.
3. Убедитесь, что оба workflow — `.github/workflows/uncensor-cloud.yml` и `.github/workflows/uncensor-approve.yml` — активны.
4. Откройте меню трека (три точки) и выберите **«Найти без цензуры»**. При уверенном совпадении замена сохранится автоматически, иначе откроется панель для выбора и подтверждения.

Подробная инструкция: `setup-ru.html` в архиве аддона.

## Ограничения

- Приватные репозитории не поддерживаются.
- Лимиты GitHub Releases и Actions зависят от аккаунта.
- В `library` хранится один файл на трек: старые версии удаляются автоматически, удаление связи владельцем удаляет и файл.
- Публикация аудио не означает, что у вас есть права на его распространение. Ответственность за контент несёт владелец репозитория. Публикуйте только записи, на которые у вас есть права.
- Аддон не обходит авторизацию, платный доступ или технические средства защиты сервисов.
