# stupidCensor

Облачная библиотека замен для цензурированных треков Яндекс Музыки.

Аддон ищет альтернативные записи через GitHub Actions, даёт прослушать кандидатов и сохраняет выбранный файл в Releases вашего публичного репозитория. После публикации запись попадает в `list.json` и автоматически регистрируется как подмена для трека по его ID.

## Что важно

- Нужен **публичный** GitHub-репозиторий: аудио должно открываться без авторизации.
- Нужен fine-grained token с правами **Contents: Read and write**, **Actions: Read and write**, **Metadata: Read**. Для классического token — `repo` и `workflow`.
- Автосохранение выполняется только при уверенном совпадении; при сомнении аддон открывает панель для подтверждения. Прослушивание записи всё равно рекомендуется.
- Источники YouTube и SoundCloud могут быть недоступны с IP GitHub Actions. Это ограничение источников, а не гарантия результата.
- Аудио перекодируется в M4A/AAC 160 kbps для совместимости с плеером.
- Токен хранится в локальном хранилище аддона, если включена галочка «Хранить токен». Не публикуйте его.

## Установка

1. Разместите файлы из папки `repository-template` (в архиве выпуска) в корне публичного репозитория.
2. Создайте токен и подключите репозиторий в разделе **«Мой GitHub»**.
3. Убедитесь, что workflow из `.github/workflows/uncensor-cloud.yml` активен.
4. Откройте меню трека (три точки) и выберите **«Найти без цензуры»**. При уверенном совпадении замена сохранится автоматически, иначе откроется панель для выбора и подтверждения.

Подробная инструкция: `setup-ru.html` в архиве аддона.

## Ограничения

- Приватные репозитории не поддерживаются.
- Лимиты GitHub Releases и Actions зависят от аккаунта.
- Старые preview-файлы не удаляются автоматически.
- Публикация аудио не означает, что у вас есть права на его распространение. Ответственность за контент несёт владелец репозитория.
- Аддон не обходит авторизацию, платный доступ или технические средства защиты сервисов.
