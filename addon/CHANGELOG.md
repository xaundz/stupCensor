# Changelog

## 1.3.1

- Упрощена настройка YouTube: импорт cookies.txt и загрузка секрета GitHub из аддона.
- Cookies проверяются, отбираются только для YouTube и шифруются публичным ключом GitHub без локального сохранения.
- Результат проверки YouTube показывается рядом с загрузкой; ошибки формата и прав Secrets объясняются в панели.

## 1.3.0

- Убрана автоматическая подмена выбранного источника резервным: сохраняется только выбранная запись.
- Для новых поисков и публикаций оставлены YouTube и SoundCloud; старые записи библиотеки не удаляются.
- У каждой публикации уникальный URL аудио, чтобы кеш плеера не возвращал предыдущий файл.
- Исправлены обновление библиотеки после публикации, удаление файлов и гонки статусов одного трека.
- Поиск провайдеров, проверки и опрос статусов выполняются с ограниченной параллельностью.
- Публикации и удаления одного трека сериализованы между основным и approval workflow.
- Добавлены встроенное прослушивание источников и режим тестирования пользователя для владельца.

## 1.2.0

- Общая библиотека подключается при первом запуске без токена.
- Поиск и выбор записи доступны через заявки GitHub без collaborator-доступа и прав на Actions или Contents.
- Публикация заявки начинается только после решения владельца; существующие записи защищены от замены пользователями.
- Добавлена очередь заявок владельца с принятием и отклонением в аддоне или на GitHub.
- Права владельца проверяются по GitHub-аккаунту и сбрасываются при выходе или смене авторизации.

## 1.1.4

- Исправлено перекодирование M4A: выходной файл больше не совпадает со скачанным входным файлом.
- Ошибки декодирования запускают резервный источник; заблокированные YouTube-кандидаты не расходуют лимит попыток.
- Cookies YouTube не мешают другим источникам, проверяются без вывода содержимого и не перезаписываются между запросами.
- Добавлены EJS-компоненты и Node.js для извлечения форматов YouTube.

## 1.1.3

- Добавлена проверка YouTube из настроек: аддон запускает безопасный тест секрета `YTDLP_COOKIES` без скачивания и показывает результат в «Заданиях».
- В настройках появилась инструкция по экспорту cookies и ссылка на секреты Actions.
- Поиск источников расширен: Rutube и Dailymotion в дополнение к YouTube и SoundCloud.
- «Добавить свою ссылку» принимает не только прямые аудиофайлы, но и страницы YouTube, SoundCloud, Rutube, Dailymotion, Vimeo, Bandcamp и VK.
- SoundCloud-трек с DRM теперь перепроверяется при подтверждении и автоматически уступает место резервному источнику.
- Обновлены подписи провайдеров, стили, документация и тесты worker (38 тестов).

## 1.1.2

- Убрана лишняя кнопка-стрелка из плеера; действия остаются в меню трека.
- Добавлена общая библиотека для друзей: подключение без токена, локальное скрытие замен.
- Добавлены роли GitHub: журнал и удаление из индекса/Releases доступны только владельцу.
- Добавления друзей проходят через GitHub Issues: владелец подтверждает меткой `uncensor-approved` или отклоняет `uncensor-rejected`; замена существующих записей остаётся только у владельца.
- Добавлен массовый поиск треков из текущей очереди.
- SoundCloud-треки с DRM помечаются как недоступные; при сбое выбранного источника worker пробует резервный.
- YouTube: поддержка cookies через секрет `YTDLP_COOKIES`, убран принудительный User-Agent.
- Исправлено сообщение об ошибке скачивания и синхронизация библиотеки после публикации.

## 1.1.1

- Поиск теперь работает только с метаданными: аудио не скачивается и не публикуется до подтверждения.
- Убраны временные preview-файлы и релиз `previews`; устаревший релиз очищается автоматически.
- В релизе `library` остаётся только одна версия трека: старые assets удаляются при публикации и удалении связи.
- Удаление старых данных `history` из `list.json`.
- Добавлены ETA, прогресс и отмена заданий GitHub Actions.
- Панель упрощена и переоформлена: компактные карточки трека, заданий и библиотеки.
- Удалены настройки паузы Яндекс Музыки при предпросмотре и авто-возобновления.
- Обновлены документация, ограничения по авторским правам и шаги установки.

## 1.1.0

- Действия перенесены в меню трека (три точки): «Найти без цензуры» и «stupidCensor: открыть».
- Убрана постоянно видимая кнопка из плеера.
- Автопоиск запускается одним пунктом меню.
- Уверенные совпадения сохраняются в GitHub автоматически; при сомнении открывается панель подтверждения.
- Добавлена пометка **SC** для треков с активной заменой.

## 1.0.0

- Первый публичный выпуск.
- Поиск кандидатов через GitHub Actions и yt-dlp.
- Предпросмотр записей перед публикацией.
- Публикация выбранного аудио в GitHub Releases.
- Публичный индекс `list.json` и автоматическая регистрация подмен.
- Ручное добавление по прямой HTTPS-ссылке.
- Управление библиотекой, заданиями, токеном и репозиторием.
- Проверка доступности аудиофайла.
